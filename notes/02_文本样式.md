CSS 文本样式用于控制网页中文字的外观，包括字体、颜色、对齐、间距等，

主要分为两大类：**字体样式** 和 **文本布局**。

**核心注意**：文字是无法直接通过 CSS 来更改样式的，必须要用适合的标签来包裹它们，本质是修改标签样式，里面的文字跟随样式变化。

## 一、字体样式（Font Styles）

| 属性 | 说明 |
| --- | --- |
| `color` | 设置字体颜色 |
| `font-family` | 字体族 |
| `font-size` | 字体大小 |
| `font-style` | 字体风格（斜体/正常） |
| `font-weight` | 字体粗细 |
| `text-decoration` | 字体装饰（下划线等） |

### 1.1 字体颜色 color

颜色是文字最直观的视觉属性，通过 `color` 属性即可为文字设置不同的颜色。

最常见的三种颜色指定方式：

#### （1）关键字

学习时使用，生产环境不常用。

```css
p {
    color: red;
    color: pink;
    color: blue;
}
```

#### （2）十六进制（最常用）

实际开发中从设计稿直接复制即可。

```css
p {
    color: #FF0000;  /* 红色 */
    color: #F00;     /* 红色简写 */
    color: #3366cc;  /* 蓝色 */
}
```

#### （3）rgb/rgba 格式

```css
p {
    color: rgb(255, 0, 0);        /* 红色 */
    color: rgba(255, 0, 0, 0.3);  /* 红色，30%不透明度 */
}
```
> `rgba` 最后一个数值取值 0~1，0 完全透明，1 完全不透明。

**总结**：学习用关键字，开发用十六进制，特殊情况用 rgb/rgba。

### 1.2 字体族 font-family

字体族决定了文字使用哪种字体外观，是页面整体风格的重要基础。

给定一个有先后顺序的字体列表，浏览器会选择列表中第一个该计算机上已安装的字体。

```css
body {
    font-family: Arial, Helvetica, sans-serif;
}
```

属性值用**逗号**隔开。

**实际开发中直接复制即可**，无需记忆。例如：

```css
/* 小米字体 */
font-family: Helvetica Neue, Helvetica, Arial, Microsoft Yahei, Hiragino Sans GB, Heiti SC, WenQuanYi Micro Hei, sans-serif;
/* 京东字体 */
font-family: PingFang SC, Source Han Sans CN, Microsoft YaHei, Heiti SC, tahoma, arial, Hiragino Sans GB, sans-serif;
```

### 1.3 字体大小 font-size

字体大小直接影响文字的可读性和页面层级，是排版中最常用的属性之一。

```css
p {
    font-size: 18px;
}
```

- `px`（像素）是 CSS 中的**绝对单位**
- 不同浏览器默认字体大小不一样，**谷歌默认 16px**
- 建议给 `body` 统一指定大小，做到浏览器统一

```css
body {
    font-size: 16px;
}
```

### 1.4 字体风格 font-style

字体风格用于控制文字是否倾斜，从而表达强调或特殊语气。

用来打开和关闭文本斜体。

| 属性值 | 说明 |
| --- | --- |
| `normal` | 普通字体（关闭斜体） |
| `italic` | 斜体版本（如果可用） |

**最常见用途**：让 `em` 或 `i` 标签取消默认倾斜。

```css
em {
    font-style: normal;
}
```

### 1.5 字体粗细 font-weight

字体粗细用于控制文字的厚重程度，是区分标题与正文、突出重点的常用手段。

| 属性值 | 说明 |
| --- | --- |
| `normal` | 正常粗细 |
| `bold` | 加粗 |
| `400` | 正常粗细（常用） |
| `700` | 加粗（常用） |

取值范围 100~900，常用 400 和 700。

**使用场景**：

1. 很多标题默认加粗，用 CSS 取消加粗
2. 部分文字需要加粗突出

```css
h1 {
    font-weight: 400;  /* 取消标题加粗 */
}
p {
    font-weight: 700;  /* 加粗 */
}
```

### 1.6 字体装饰 text-decoration

| 属性值 | 说明 |
| --- | --- |
| `none` | 取消文本装饰 |
| `underline` | 下划线 |
| `overline` | 上划线 |
| `line-through` | 穿过文本的线（删除线） |

**使用场景**：

1. 最常见：取消链接下划线
2. 特殊情况：添加删除线

```css
a {
    text-decoration: none;  /* 取消下划线 */
}
del {
    text-decoration: line-through;  /* 删除线 */
}
```

### 1.7 字体样式总结

| 属性 | 描述 | 常见取值 | 示例 |
| --- | --- | --- | --- |
| `color` | 设置文本颜色 | 颜色名称、十六进制、RGB、RGBA | `color: #3366cc;` |
| `font-family` | 设置字体系列 | 无衬线字体等 | `font-family: "Microsoft YaHei", sans-serif;` |
| `font-size` | 设置文字大小 | px | `font-size: 16px;` |
| `font-style` | 设置文字样式 | `normal`、`italic` | `font-style: normal;` |
| `font-weight` | 设置文字粗细 | 数值 100~900、`normal`、`bold` | `font-weight: 700;` |
| `text-decoration` | 设置文字装饰 | `none`、`underline`、`overline`、`line-through` | `text-decoration: underline;` |

## 二、文本布局（Text Layout）

| 属性 | 说明 |
| --- | --- |
| `text-align` | 文本对齐 |
| `text-indent` | 首行缩进 |
| `letter-spacing` | 字符间距 |
| `line-height` | 行高 |

### 2.1 文本对齐 text-align

控制文本在它所在的**块级盒子**内如何水平对齐。

| 属性值 | 说明 |
| --- | --- |
| `left` | 左对齐（默认） |
| `right` | 右对齐 |
| `center` | 水平居中对齐 |
| `justify` | 两端对齐（自动改变字间距） |

**使用场景**：

1. 文本/图片在盒子内水平对齐
2. 文章文字两端对齐（如腾讯体育）

```css
h1 {
    text-align: center;
}
p {
    text-align: justify;  /* 两端对齐 */
}
```
> **注意**：`text-align` 仅对**块级元素**生效。

### 2.2 首行缩进 text-indent

设置块级元素中文本行前面空格（缩进）的长度。

**使用场景**：

1. 段落首行缩进 2 个字
2. Logo 隐藏文字效果

```css
p {
    text-indent: 2em;  /* 缩进 2 个汉字 */
}
```
> `em` 是**相对单位**，1em 等于当前元素的字体大小。如果当前元素没有设置大小，则按照父元素文字大小。

> **注意**：`text-indent` 仅对**块级元素**生效。

### 2.3 字间距 letter-spacing

设置文本字符之间的间距。

**使用场景**：调整字与字之间距离，提升用户体验。

```css
p {
    letter-spacing: 2px;
}
```
> 负值可使字符重叠（需谨慎使用）。

### 2.4 行高 line-height

设置文本每行之间的高度。

**使用场景**：

1. 设置多行文本之间的上下间距
2. **让单行文本垂直居中**

| 属性值 | 说明 |
| --- | --- |
| `数字px` | 固定像素值 |
| `数字不带单位` | 当前字体大小的倍数 |

```css
p {
    line-height: 25px;   /* 固定行高 */
    line-height: 1.5;    /* 当前字体大小的 1.5 倍 */
}
```

**核心技巧：单行文本垂直居中**

行高 = 盒子高度 → 单行文字垂直居中

```css
.box {
    height: 40px;
    line-height: 40px;  /* 行高等于盒子高度 */
}
```

### 2.5 文本布局总结

| 属性 | 作用 | 核心取值 | 注意事项 | 示例 |
| --- | --- | --- | --- | --- |
| `text-align` | 水平对齐方式 | `left`、`right`、`center`、`justify` | 仅对块级元素生效 | `p {text-align: center;}` |
| `text-indent` | 首行缩进量 | 长度值（`20px`、`2em`） | 仅对块级元素生效 | `p {text-indent: 2em;}` |
| `letter-spacing` | 字符间距 | 数值 | 负值可使字符重叠 | `h1 {letter-spacing: 2px;}` |
| `line-height` | 行与行之间的垂直间距 | 像素或倍数 | 行高=高度，单行垂直居中 | `p {line-height: 1.6;}` |

## 三、font 简写

`font` 简写属性可以在一个声明中设置多个字体属性。

**使用场景**：给整个页面设置相关字体样式。

```css
/* 小米官网写法 */
body {
    font: 14px/1.5 Helvetica Neue, Helvetica, Arial, Microsoft Yahei, Hiragino Sans GB, Heiti SC, WenQuanYi Micro Hei, sans-serif;
    color: #333;
}
/* 京东官网写法 */
body {
    font: 12px/1.5 PingFang SC, Source Han Sans CN, Microsoft YaHei, Heiti SC, tahoma, arial, Hiragino Sans GB, sans-serif;
    color: #666;
}
```

**语法格式**：

```css
font: [font-style font-variant font-weight]?  font-size  [/line-height]?  font-family
         ↑ 可选，且应在 size 之前              ↑必填        ↑可选        ↑必填
> 实际开发中，直接复制大厂的字体设置即可。
```

## 四、CSS 继承性

**子元素自动继承父元素的某些 CSS 样式属性。**

- 主要继承跟**文字相关**的样式属性：字体、颜色、文本对齐等
- 但如果子元素自己定义了样式，会**优先使用自己的样式**

```css
/* 父元素设置 */
body {
    font-size: 16px;
    color: #333;
    text-align: center;
}
/* 子元素 p 自动继承这些样式，但如果 p 自己定义了 color，则用自己的 */
p {
    color: red;  /* 覆盖继承的 color: #333 */
}
```
> **特殊情况**：`h` 标签默认加粗，`a` 标签默认有下划线，这些**不能通过继承性修改父级来实现取消**，需要单独指定 `h` 和 `a` 的样式。
