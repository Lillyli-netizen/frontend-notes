# 字体图标与精灵图

> 原文：[CSDN](https://blog.csdn.net/qq_63283852/article/details/164508685)

---

## 一、字体图标（Icon Fonts）

#### 1. 什么是字体图标？

**字体图标**是一种将图标以**字体字形**的形式嵌入网页的技术。开发者像使用普通文字一样使用图标，通过 CSS 控制其颜色、大小、阴影等样式。

```html
<!-- 像文字一样使用图标 -->
<i class="iconfont icon-home"></i>
<span class="iconfont icon-user"></span>
```

#### 2. 使用场景

| 场景 | 说明 |
| --- | --- |
| **导航菜单图标** | 首页、分类、购物车、个人中心等导航项前置图标 |
| **按钮操作图标** | 搜索（放大镜）、刷新、分享、点赞、收藏等 |
| **表单/输入框装饰** | 输入框前的用户图标、密码锁图标、搜索框内的放大镜 |
| **结合动画效果** | 配合 `transition` 或 `animation` 实现图标旋转、缩放、变色等交互反馈 |
| **状态标识** | 成功（✓）、警告（⚠️）、信息（ℹ️）等 |

#### 3. 核心优势

| 优势 | 详细说明 |
| --- | --- |
| **矢量缩放（无损）** | 字体图标本质是矢量图形，放大缩小**不会模糊**，完美适配 Retina 高清屏 |
| **样式灵活** | 通过 CSS 直接修改 `color`、`font-size`、`text-shadow`、`opacity` 等属性，无需重新切图 |
| **减少 HTTP 请求** | 一个字体文件（`.woff` / `.ttf`）通常包含几百个图标，只需加载**一次**，比多张小图片更高效 |
| **兼容性好** | 支持所有现代浏览器（Chrome、Firefox、Safari、Edge），甚至兼容 IE8+ |
| **文件体积小** | 字体文件经过压缩后体积很小（通常几十 KB），对加载速度影响极小 |

#### 4. 主流图标库

| 图标库 | 特点 | 官网地址 |
| --- | --- | --- |
| **iconfont（阿里字体库）** | **国内最常用，免费**，包含淘宝/阿里妈妈图标库，支持自定义图标项目 | [iconfont-阿里巴巴矢量图标库](http://www.iconfont.cn/ "iconfont-阿里巴巴矢量图标库") |
| **Font Awesome** | 图标最全，支持免费版和 Pro 付费版 | [fontawesome.com](https://fontawesome.com/ "fontawesome.com") |
| **Bootstrap Icons** | Bootstrap 生态内的图标，简洁易用 | [icons.getbootstrap.com](https://icons.getbootstrap.com/ "icons.getbootstrap.com") |
| **IcoMoon** | 最早推出自定义图标字体生成器的平台，支持上传 SVG 自定义生成 | [icomoon.io](https://icomoon.io/ "icomoon.io") |

> **实际开发中，国内项目几乎都用 iconfont**，因为它免费、图标全、支持自定义项目。生产环境建议把字体文件下载到本地随项目发布，或使用国内稳定的 CDN（如 unpkg 国内镜像、字节静态资源等）；大型项目更倾向用 SVG 图标（如 iconify、svg sprite），比字体图标更灵活，还能支持多色。

#### 5. 使用步骤（以 iconfont 为例）

#### 第一步：下载或在线引入字体图标文件

**方式一：下载到本地（生产环境推荐）**

在 [iconfont.cn](https://iconfont.cn/ "iconfont.cn") 中选好图标 → 加入购物车 → 添加到项目 → 点击“下载至本地”，把字体文件和 CSS 一并放入项目目录，随项目一起发布。

```html
<!-- 本地引入（推荐，随项目走，不依赖外部网络） -->
<link rel="stylesheet" href="./fonts/iconfont.css">
```

**方式二：在线引入（仅适合临时演示，不推荐用于生产）**

在 [iconfont.cn](https://iconfont.cn/ "iconfont.cn") 中选好图标 → 加入购物车 → 添加到项目 → 生成在线链接 → 复制 `<link>` 到 HTML 中。这种方式依赖第三方 CDN，国内网络环境下可能加载不稳定，一般只用于快速验证效果。

- `iconfont.css`（核心样式文件）
- `iconfont.woff` / `iconfont.ttf` / `iconfont.eot`（字体文件，不同浏览器兼容）
- `iconfont.svg`（矢量源文件）

将上述文件放入项目的 `fonts/` 或 `css/` 目录下，随项目一起提交到代码仓库，保证部署后图标始终可用。

#### 第二步：在 HTML 中引入 CSS 文件

```html
<!-- 本地引入 -->
<link rel="stylesheet" href="./fonts/iconfont.css">
```

#### 第三步：在 HTML 中使用字体图标

在需要显示图标的位置，添加一个空标签（常用 `<i>` 或 `<span>`），设置**两个类名**：

1. `iconfont`（基础类，声明字体家族）
2. `icon-xxx`（具体图标的类名，由 iconfont 自动生成）

```html
<!-- 基础用法 -->
<i class="iconfont icon-home"></i>
<span class="iconfont icon-cart"></span>
<!-- 结合文字使用 -->
<a href="#">
    <i class="iconfont icon-user"></i> 个人中心
</a>
```

#### 第四步：通过 CSS 调整图标样式

因为图标本质是**文字**，所以所有文字样式都生效：

```css
.iconfont {
    font-size: 24px;        /* 调整大小 */
    color: #ff5000;         /* 修改颜色 */
    font-weight: bold;      /* 加粗 */
    text-shadow: 0 2px 4px rgba(0,0,0,0.2); /* 阴影 */
    transition: all 0.3s;   /* 过渡动画 */
}
/* 鼠标经过变色 */
.iconfont:hover {
    color: #ff6a00;
    transform: scale(1.2);  /* 放大 */
}
```

#### 6. 字体图标与普通图片的对比

| 对比维度 | 字体图标 | 普通图片（PNG/JPG） |
| --- | --- | --- |
| **缩放质量** | 矢量无损，任意缩放不模糊 | 位图，放大后模糊/锯齿 |
| **颜色修改** | CSS 直接改 `color`，一行代码 | 需要重新切图或 CSS filter |
| **大小修改** | CSS 改 `font-size` | 需要重新切图或 CSS 宽高（可能变形） |
| **HTTP 请求** | 一个字体文件包含全部图标（1次请求） | 每个图标一张图（N 次请求） |
| **语义化** | 较差（`<i>` 标签本身无语义） | 较好（`<img alt="首页">`） |
| **适用场景** | 单色、扁平风格图标 | 彩色、渐变色、复杂细节图标 |

## 二、CSS 精灵图（CSS Sprites）

#### 1. 什么是精灵图？

**CSS 精灵图**（也叫 CSS Sprites、雪碧图）是一种将**多个小图标或小图片合并到一张大图**中，然后通过 CSS 的 `background-position` 属性来控制显示其中**特定部分**的技术。

> 你可以把精灵图想象成一张**电影胶片**，每一帧是一个小图标。我们通过移动胶片的位置（`background-position`），让盒子的“取景框”对准我们想看的那个画面。

#### 2. 使用场景

| 场景 | 说明 |
| --- | --- |
| **导航菜单图标** | 网站导航栏中多个彩色小图标 |
| **按钮状态图标** | 按钮的 正常/悬停/点击 不同状态用同一张图的三个不同位置 |
| **复杂彩色小图标** | 图标带有渐变色、阴影等复杂视觉效果，不适合字体图标 |
| **游戏/应用内元素** | 游戏中的角色、道具、技能图标等 |
| **背景装饰图案** | 页面中重复使用的装饰性小元素 |

#### 3. 核心优势

| 优势 | 详细说明 |
| --- | --- |
| **大幅减少 HTTP 请求** | N 个小图标 → 1 张大图，只需**1 次 HTTP 请求**，显著提升页面加载速度 |
| **减少网络开销** | 尤其在移动端或低带宽环境下，减少请求数比减少总大小更重要 |
| **统一管理** | 所有图标集中在一张图上，方便维护和版本更新 |
| **提前加载** | 一次加载即可使用全部图标，不存在“图标逐个闪现”的问题 |

#### 4. 核心原理（三步走）

1. **给盒子设置固定宽高**：盒子相当于一个“取景框”，只显示大图中对应区域。
2. **给盒子添加背景图片**：背景图片就是那张合并好的大图。
3. **通过 `background-position` 移动背景图**：把大图中目标图标的位置，移动到盒子取景框内。

#### 5. 关键：网页坐标系（非常容易出错）

在网页中，坐标系的**原点 (0, 0)** 在**左上角**：

- **X 轴**：向右为正（→ 正）
- **Y 轴**：向下为正（↓ 正）

**`background-position` 的取值逻辑**：

- `background-position: x y;` 中的 x 和 y，表示**背景图左上角相对于盒子左上角的偏移量**。
- 假设目标图标在精灵图中的坐标为 **(x, y)**（即图标左上角距离大图左上角的距离），那么我们要把背景图向左、向上移动，公式为：

> **`background-position: -xpx -ypx;`**

**示例**：

假设精灵图 `sprites.png` 宽 600px、高 400px，里面包含如下图标：

| 图标 | 在大图中的位置（左上角坐标） | 图标尺寸 |
| --- | --- | --- |
| 首页图标 | (0, 0) | 20px × 20px |
| 搜索图标 | (100, 0) | 20px × 20px |
| 购物车图标 | (200, 0) | 20px × 20px |
| 用户图标 | (0, 50) | 20px × 20px |

如果要显示**搜索图标**：

```css
.search-icon {
    width: 20px;
    height: 20px;
    background-image: url(./sprites.png);
    background-position: -100px 0px;   /* 往左移动100px */
}
```

如果要显示**用户图标**：

```css
.user-icon {
    width: 20px;
    height: 20px;
    background-image: url(./sprites.png);
    background-position: 0px -50px;    /* 往上移动50px */
}
```
> **记忆口诀**：想要背景图往**左**移，`x` 写**负值**；想要背景图往**上**移，`y` 写**负值**。

#### 6. 精灵图的 CSS 核心属性

```css
.icon {
    /* 1. 固定宽高（取景框尺寸 = 图标尺寸） */
    width: 20px;
    height: 20px;
    /* 2. 设置背景图 */
    background-image: url(./sprites.png);
    /* 3. 禁止平铺（重要） */
    background-repeat: no-repeat;
    /* 4. 定位到目标图标（关键） */
    background-position: -100px -50px;
}
```

**现实开发：**下面是一个真实项目中的写法。假设 UI 设计师给了一张精灵图 `wz.webp`，其中每个小图标尺寸约为 27px × 26px，我们通过「基础类 + 定位类」组合的方式，让多个图标共用同一张背景图：

```css
<style>
    /* 基础类：只负责取景框尺寸 + 背景图，不写定位 */
    .box {
        width: 27px;
        height: 26px;
        background: url(./img/wz.webp) no-repeat;
    }
    /* 定位类：每个图标一个类名，只改 background-position */
    .sprite {
        background-position: 0 -169px;
    }
    .sprite2 {
        background-position: -90px -170px;
    }
</style>

<!-- 使用时：基础类 + 定位类 组合 -->
<div class="box sprite"></div>
<div class="box sprite2"></div>
```

这种「基础类 + 定位类」的写法是实际项目中最常用的模式：**基础类**统一管理宽高和背景图，避免每个图标重复写一遍；**定位类**只负责各自的 `background-position`，新增图标时只需追加一个类名，维护成本低、代码更干净。

如果图标需要支持鼠标悬停换图（比如按钮的正常态和悬停态），可以配合 `:hover` 切换定位类：

```css
.btn-icon {
    width: 27px;
    height: 26px;
    background: url(./img/wz.webp) no-repeat;
    background-position: 0 -169px;   /* 正常态 */
}
.btn-icon:hover {
    background-position: 0 -195px;   /* 悬停态：同一张图往下偏移 */
}
```
> **注意**：`background-position` 除了可以用 `px` 精确值，也可以用 `center`、`top`、`left` 等方位词，但精灵图场景下为了精准，**必须用具体的 px 值**。

#### 7. 精灵图使用流程（实际开发）

| 步骤 | 操作 |
| --- | --- |
| **1. 设计合并** | UI 设计师将多个小图标合并为一张大图（或使用工具自动合成），并提供**每个图标在大图中的坐标和尺寸** |
| **2. 测量坐标** | 使用 Photoshop / Figma / 像素测量工具，获取目标图标左上角距离大图左上角的 `x` 和 `y` 值 |
| **3. 编写 CSS** | 设置盒子宽高 = 图标尺寸，`background-position` = `-xpx -ypx` |
| **4. 复用类名** | 给不同图标设置不同类名，每个类名对应不同的 `background-position` |

## 三、字体图标 vs 精灵图（怎么选）

下面从几个关键维度把两者放在一起对比，方便快速做选型判断。

| 对比维度 | 字体图标（Icon Fonts） | 精灵图（CSS Sprites） |
| --- | --- | --- |
| **缩放质量** | 矢量无损，任意缩放不模糊 | 位图，放大后模糊/锯齿 |
| **颜色修改** | CSS 直接改 `color`，一行代码 | 不能直接改颜色，除非用 CSS filter（有兼容性问题且效果有限） |
| **HTTP 请求** | 一个字体文件包含全部图标（1 次请求） | 一张大图包含全部图标（1 次请求） |
| **语义化** | 较差（`<i>` / `<span>` 本身无语义，需加 `aria-hidden`） | 背景图无语义，需额外加 `alt` 或 `aria-label` |
| **适用场景** | 单色、扁平风格图标，导航菜单、按钮、纯展示型图标 | 彩色、渐变色、复杂细节图标，固定尺寸的装饰元素、游戏/应用图标 |
| **维护成本** | 低，增删改图标只需更新字体文件 | 高，增删图标需要重新合成大图，坐标全部重新计算 |

**选型结论：**没有绝对的好坏，关键看图标形态。单色、扁平、需要频繁换色或缩放的图标，优先用字体图标，省事且灵活；彩色、渐变色、带复杂细节的图标，用精灵图更合适。两者也可以混用，各取所长。

## 四、实际开发建议

#### 什么时候用 字体图标？

- 图标风格统一、单色、扁平化设计（如绝大多数后台管理界面、移动端 APP 底部导航）。
- 需要频繁调整颜色或大小（如换肤功能、响应式适配）。
- 团队没有专业 UI 设计师，直接用 iconfont 社区图标即可。

#### 什么时候用 精灵图？

- 图标色彩丰富、包含渐变色或阴影（如电商平台的首字母大图标、品牌 Logo 合集）。
- 需要展示高精度、固定尺寸的图标（不需要缩放）。
- 历史遗留项目或 UI 设计稿已经提供了合成好的精灵图。
- 对字体图标兼容性有顾虑（IE8 以下对字体图标支持较差，但如今已极少见）。

#### 两者可以混用吗？

**当然可以！** 实际大型项目中，两者经常搭配使用：

- **导航/工具栏的单色图标** → 用字体图标，方便换色和缩放。
- **品牌 Logo、彩色促销标签、会员等级徽章** → 用精灵图或独立图片，保留色彩和细节。

各自发挥各自的优势，互不冲突。
